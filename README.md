# Personal Portfolio — Isaac Kaba

Welcome to the repository of my personal portfolio website! Designed to showcase my projects, work experience, and technical skills as a Computer Engineering student at EPITA.

🔗 **Live Demo:** [isaackaba.vercel.app](https://isaac-kaba.vercel.app) 

---

## Tech Stack & Tools

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animation & Canvas:** HTML5 Canvas API (custom interactive background)
- **Deployment:** [Vercel](https://vercel.com/)

---

## Features

- **Modern & Clean UI:** Warm, minimalist aesthetic with pastel geometric background animations.
- **Interactive Elements:** Smooth scrolling, custom typewriter header, and responsive layout.
- **Project Showcase:** Highlights key projects including Optical Character Recognition (C/GTK), Machine Learning Stock Prediction (Python), and Unity 2D Game Development (C#).
- **Direct Links:** Fast access to GitHub repositories, technical reports (PDF), LinkedIn, and direct email contact.
